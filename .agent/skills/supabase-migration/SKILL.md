# Create a Supabase Schema Migration

This project uses **Alembic** against Supabase's Postgres connection string — not the Supabase CLI's own migration flow (see `erd-schema` for why). Every migration must match the finalized 27-entity model exactly; never invent a table/column that isn't already in `erd-schema`.

## 1. Before writing the migration

- Confirm the table/column/relationship already exists in the `erd-schema` skill. If it doesn't, that's a schema-design discussion for the team first, not something to just add.
- Check whether the new table introduces a many-to-many relationship — if so, it needs a bridge entity (see `PROJECT_ASSIGNMENT` / `EMPLOYEE_SKILL` as the existing examples), never a direct FK on both sides.

## 2. Generate and name it

```bash
alembic revision --autogenerate -m "<entity_name>: <what changed>"
# e.g. "leave_request: add leave_policy_id FK"
```

## 3. Review the autogenerated migration for these specifically

- Every new FK has `ondelete` behavior decided deliberately (don't leave Alembic's default) — cascade for owned child records (e.g. `TASK_COMMENT.task_id`), restrict/nullify for references to shared-kernel entities (e.g. anything pointing at `EMPLOYEE.employee_id`)
- New nullable vs. required columns match what `erd-schema` says (e.g. `PROJECT.client_id` is nullable, `PROJECT.project_manager_id` is not)
- Migration is reversible — check the generated `downgrade()` actually drops what `upgrade()` created

## 4. Row Level Security reminder

If the new table holds data that should be role- or ownership-scoped (most tables do — see `rbac-enforcement`), flag in the PR description that an RLS policy may be needed, even if you're not writing the SQL policy in this same migration. RLS policies are a second line of defense behind `core/rbac.py`, not a replacement for the application-level check.

## 5. Apply and verify

```bash
alembic upgrade head
```
Confirm against the Supabase dashboard's table editor that the new schema matches what you intended — autogenerate occasionally misses a constraint or index.
